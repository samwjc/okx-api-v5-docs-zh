## 获取返佣指引

OKX Broker 经纪商进行 OKX API 接口调用时，当请求参数有"tag"时，请务必录入您专属的 Broker code 信息，实现订单与经纪商的关联。  
当订单录入 BrokerCode 信息后，经纪商方可享受对应的佣金奖励、数据统计等特定逻辑追踪
