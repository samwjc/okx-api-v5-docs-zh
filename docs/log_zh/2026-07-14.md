## Stable Rewards 询价、下单及历史记录接口下线

`POST /api/v5/finance/stable-rewards/quote`、`POST /api/v5/finance/stable-rewards/trade` 及 `GET /api/v5/finance/stable-rewards/subscribe-redeem-history` 接口已停用并从 API 中移除。如需交易 USDG 等稳定币，请使用标准[订单簿交易 API](/zh/order-book-trading)。
