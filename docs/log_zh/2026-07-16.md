## 交易产品接口支持 Pre-market X-Perp

欧易现已支持 Pre-market X-Perp —— 一种在标的代币正式上线前于盘前阶段交易的永续型 `FUTURES` 合约。Pre-market X-Perp 通过 `ruleType = pre_market` 与 `instType = FUTURES` 组合进行标识。当其转换为正常 X-Perp 后，`ruleType` 变为 `xperp`，并且 `preMktSwTime` 会填充为转换时间戳。

*   以下接口扩展为返回 Pre-market X-Perp 合约（通过 `instType=FUTURES` 查询）：
    
    *   [GET / 获取交易产品基础信息（public）](/zh/public-data-rest-api-get-instruments)
    *   [GET / 获取交易产品基础信息（private）](/zh/trading-account-rest-api-get-instruments)
    *   [WS / 产品频道](/zh/public-data-websocket-instruments-channel)
*   扩展以下响应参数的适用范围：
    

<table><thead><tr><th><strong>参数名</strong></th><th><strong>类型</strong></th><th><strong>描述</strong></th></tr></thead><tbody><tr><td>ruleType</td><td>String</td><td>交易规则类型。<br><code>normal</code><br><code>pre_market</code>：盘前交易产品（含 Pre-market X-Perp <code>FUTURES</code>）<br><code>rebase_contract</code><br><code>xperp</code><br>Pre-market X-Perp 在盘前阶段返回 <code>pre_market</code>，转换为正常 X-Perp 后变为 <code>xperp</code>。</td></tr><tr><td>preMktSwTime</td><td>String</td><td>盘前交易产品切换为正常交易的时间，Unix 时间戳，单位为毫秒。<br>仅适用于盘前 <code>SWAP</code> 与 Pre-market X-Perp <code>FUTURES</code>。当 Pre-market X-Perp 转换为正常 X-Perp 时填充。</td></tr></tbody></table>
