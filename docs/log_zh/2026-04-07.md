## 下单需要 KYC 二级或以上认证

OKX 将要求用户完成 **KYC 二级或以上认证**，方可通过 WebSocket 和 REST API 接口下单。未完成 KYC 二级认证的用户在尝试下单时将收到错误码 `59113`。**此要求仅适用于实盘交易，模拟盘交易不受影响。**
