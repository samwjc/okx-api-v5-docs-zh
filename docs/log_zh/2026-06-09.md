## 风险保证金 API 更新 — REST 变更与 WS 推送变更

**不兼容变更**

*   删除了 `type` 请求参数中的 `regular_update` 枚举值。`adl` 和 `platform_revenue` 类型已弃用，当前返回空值；将在后续更新中删除：
    
    *   [GET / 获取风险保证金余额](/zh/public-data-rest-api-get-insurance-fund)
*   WS `adl-warning` 频道将停止在 `normal` 状态下推送数据。在 `warning` 或 `adl` 状态下，数据继续每秒推送一次。所有字段保留，但以下字段将返回空值（`""`）。这些字段将在后续更新中删除：
    
    *   [WS / 自动减仓预警频道](/zh/public-data-websocket-adl-warning-channel)
