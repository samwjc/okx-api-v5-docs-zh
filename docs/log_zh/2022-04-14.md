*   2022年4月25日模拟盘升级预告，最早将于2022年5月5日上线实盘：
    *   新增`bbo-tbt`实时推送买卖1档的深度频道。  
        

```
{
    "op": "subscribe",
    "args": [{
        "channel": "bbo-tbt",
        "instId": "BTC-USDT"
    }]
}
```
