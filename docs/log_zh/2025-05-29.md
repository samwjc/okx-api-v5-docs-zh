## 所有 WebSocket 订阅与响应新增 id 参数

*   已新增订阅请求的可选参数`id`，适用于以下 WebSocket 路径：
    *   `/ws/v5/public`
    *   `/ws/v5/private`
    *   `/ws/v5/business`

系统将在所有相关响应消息中返回相同的`id`，帮助用户准确匹配响应与对应请求。

#### 请求参数

<table><thead><tr><th>参数名</th><th>类型</th><th>是否必须</th><th>描述</th></tr></thead><tbody><tr><td>id</td><td>String</td><td>否</td><td>消息的唯一标识。<br>用户提供，返回参数中会返回以便于找到相应的请求。<br>字母（区分大小写）与数字的组合，可以是纯字母、纯数字且长度必须要在1-32位之间。</td></tr></tbody></table>

## 新增提前挂单相关返回参数

提前挂单相关解释说明，请参考[关于欧易集合竞价和提前挂单解释说明](https://www.okx.com/zh-hans/help/call-auction-mechanism)。

*   针对行情数据，提前挂单过程中，best bid/ask按照真实订单薄数据回传，best ask的价格有机会低于best bid
    
    *   [GET / 获取所有产品行情信息](/zh/order-book-trading-market-data-get-tickers)
    *   [GET / 获取单个产品行情信息](/zh/order-book-trading-market-data-get-ticker)
    *   [WS / 行情频道](/zh/order-book-trading-market-data-ws-tickers-channel)
*   针对深度数据，返回买卖所有深度数据，best ask的价格有机会低于best bid
    
    *   [GET / 获取产品深度](/zh/order-book-trading-market-data-get-order-book)
    *   [GET / 获取产品完整深度](/zh/order-book-trading-market-data-get-full-order-book)
    *   [WS / 深度频道](/zh/order-book-trading-market-data-ws-order-book-channel)
*   新增cancelSource：43，对应提前挂单结束时的批量撤单
    
    *   [WS / 订单频道](/zh/order-book-trading-trade-ws-order-channel)
