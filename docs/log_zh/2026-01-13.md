*   下单接口新增请求参数isElpTakerAccess，仅支持`ioc`订单类型
    *   [POST / 下单](/zh/order-book-trading-trade-post-place-order)
    *   [POST / 批量下单](/zh/order-book-trading-trade-post-place-multiple-orders)
    *   [WS / 下单](/zh/order-book-trading-trade-ws-place-order)
    *   [WS / 批量下单](/zh/order-book-trading-trade-ws-place-multiple-orders)

**请求参数**

<table><thead><tr><th><strong>参数名</strong></th><th><strong>类型</strong></th><th><strong>是否必须</strong></th><th><strong>描述</strong></th></tr></thead><tbody><tr><td>isElpTakerAccess</td><td>Boolean</td><td>否</td><td>是否作为 taker 吃单 ELP<br><code>true</code>：该请求能吃单 ELP，但会被施加延迟<br><code>false</code>：该请求不能吃单 ELP，并且没有延迟<br><br>默认值为<code>false</code>，<code>true</code>仅适用于ioc订单</td></tr></tbody></table>

*   isElpTakerAccess:true 订单的限速也会受到限制
    
    *   50个/2s，限制维度为 User ID + Instrument ID
    *   该限速会在 REST 和 WebSocket 的下单及批量下单接口中共享
*   交易产品接口新增返回参数 elp 以表示一个币对是否有开启 ELP 并且用户是否有权限为该币对下 ELP 订单。这不意味着该币对一定有 ELP 挂单。
    
    *   [获取交易产品基础信息](/zh/trading-account-rest-api-get-instruments)

**返回参数**

<table><thead><tr><th><strong>参数名</strong></th><th><strong>类型</strong></th><th><strong>描述</strong></th></tr></thead><tbody><tr><td>elp</td><td>String</td><td>ELP 下单权限<br><code>0</code>：该币对不支持 ELP<br><code>1</code>：该币对支持 ELP 但用户没有权限为其下 ELP 订单<br><code>2</code>：该币对支持 ELP 且用户有权限为其下 ELP 订单<br><br><code>1/2</code>不代表深度中一定有 ELP 挂单</td></tr></tbody></table>
