## OKUSD 申购、赎回与限额 — 新增 API 接口

OKX 现已新增 OKUSD 的 V5 API 支持。API 用户可通过接口以 1:1 汇率将 USDT 申购为 OKUSD、通过即时赎回（实时到账）或标准赎回（D+5 或 D+6 自然日，取决于提交时间）将 OKUSD 赎回为 USDT，并查询当日剩余申购及赎回限额。

*   新增以下接口：
    *   [GET / 查询限额](/zh/financial-product-okusd-get-okusd-limits)
    *   [POST / 申购 OKUSD](/zh/financial-product-okusd-subscribe-okusd)
    *   [POST / 赎回 OKUSD](/zh/financial-product-okusd-redeem-okusd)
*   新增错误码 `51763`\-`51774`，涉及 OKUSD 申购与赎回：
    *   [错误码 / 金融](/zh/error-code-rest-api-finance)
