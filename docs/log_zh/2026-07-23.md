## GLP 做市商表现 API

新增两个只读接口，面向已加入 Global Liquidity Program (GLP) 的做市商查询自己的考核表现：当日快照（含当日及 MTD）和逐日历史记录。仅已加入且在有效期的 GLP 做市商可调用，子账户解析到其 master account。

*   以下为新增接口：
    *   [GET / 获取 GLP 当日表现](/zh/trading-account-rest-api-get-glp-today-performance)
    *   [GET / 获取 GLP 历史表现](/zh/trading-account-rest-api-get-glp-historical-performance)

### GET / 获取 GLP 当日表现

获取当前账户在所有已加入 GLP 业务线（Spot / Perp / Expiry & Nitro）的当日和月度累计（MTD）表现快照。无需请求参数，账户由 API key 自动解析。

#### 限速：5次/2s

#### 限速规则：User ID

#### 权限：读取

#### HTTP请求

`GET /api/v5/users/glp/today-performance`

> 请求示例

```
GET /api/v5/users/glp/today-performance
```

#### 请求参数

无。账户由登录态自动解析。

**交易量和份额结构**

`daily` 和 `mtd` 均包含 `volume`（交易量）和 `share`（份额）两个 Object。每个 Object 下含分类 key，每个分类为包含 `maker`（String）和 `taker`（String）字段的 Object。

<table><thead><tr><th><strong>分类</strong></th><th><strong>在 <code>volume</code> 中</strong></th><th><strong>在 <code>share</code> 中</strong></th><th><strong>描述</strong></th></tr></thead><tbody><tr><td>typeA</td><td>是</td><td>是</td><td>Type A。<code>FUT_NTO</code> 时为 <code>null</code></td></tr><tr><td>typeBTotal</td><td>是</td><td>否</td><td>Type B 合计。<code>FUT_NTO</code> 时为 <code>null</code></td></tr><tr><td>typeBAdj</td><td>否</td><td>是</td><td>Type B 调整后。<code>FUT_NTO</code> 时为 <code>null</code></td></tr><tr><td>tradfiX2</td><td>是</td><td>否</td><td>TradFi 量（已 ×2）。<code>FUT_NTO</code> 时为 <code>null</code></td></tr><tr><td>total</td><td>是</td><td>是</td><td>各类型合计。始终存在</td></tr></tbody></table>

*   **`volume`** 值：美元名义量，String，保留 2 位小数（如 `"1000000.00"`）
*   **`share`** 值：小数字符串，4 位小数，无 `%` 后缀（如 `"0.0000"`）

### GET / 获取 GLP 历史表现

获取单个 GLP 业务线的逐日表现记录，按日期降序排列（最新日期在前）。

#### 限速：5次/2s

#### 限速规则：User ID

#### 权限：读取

#### HTTP请求

`GET /api/v5/users/glp/historical-performance`

> 请求示例

```
GET /api/v5/users/glp/historical-performance?program=SPOT
GET /api/v5/users/glp/historical-performance?program=SPOT&begin=1751299200000&end=1753804800000&limit=31
```

## FUTURES 和 SWAP 计划委托支持追逐限价委托（Chase Order）

FUTURES 和 SWAP 计划委托（Trigger Order）现可在触发时下发**追逐限价委托（Chase Order）**——`advanceOrdType` 新增取值 `chase`，其参数由新增数组 `advChaseParams` 承载。查询接口通过新增字段 `subAlgoIdList` 返回触发后生成的追逐委托 `algoId`；在计划委托触发前，可通过改单接口修改追逐值。本期暂不支持追逐委托与附带止盈止损（`attachAlgoOrds`）同时设置。

### 策略委托下单

*   `advanceOrdType` 新增取值 `chase`，并新增 `advChaseParams` 数组；`orderPx` 变更为条件必填（追逐委托不适用）。
    *   [POST / 策略委托下单](/zh/order-book-trading-algo-trading-post-place-algo-order)

<table><thead><tr><th><strong>参数名</strong></th><th><strong>类型</strong></th><th><strong>是否必须</strong></th><th><strong>描述</strong></th></tr></thead><tbody><tr><td>advanceOrdType</td><td>String</td><td>否</td><td>计划委托的子订单类型。<br><code>fok</code>、<code>ioc</code> 或 <code>chase</code>。<br><code>chase</code> 仅适用于 FUTURES 和 SWAP。<br>默认为空（按 <code>orderPx</code> 下发限价或市价单）。</td></tr><tr><td>orderPx</td><td>String</td><td>条件必填</td><td>计划委托触发时下发订单的价格。<code>-1</code> 表示市价。当 <code>advanceOrdType</code> 为 <code>chase</code> 时不适用（追逐委托无固定价格）。</td></tr><tr><td>advChaseParams</td><td>Array of objects</td><td>条件必填</td><td>追逐参数。当 <code>advanceOrdType</code> 为 <code>chase</code> 时必填。</td></tr><tr><td>&gt; chaseType</td><td>String</td><td>条件必填</td><td>追逐距离单位。<br><code>distance</code>（默认）：与买一价/卖一价的绝对价格距离，以结算货币计。<br><code>ratio</code>：百分比。</td></tr><tr><td>&gt; chaseVal</td><td>String</td><td>条件必填</td><td>追逐值。当 <code>chaseType</code> 为 <code>distance</code> 时，为与买一价/卖一价的距离（以结算货币计）；当 <code>ratio</code> 时，<code>0.1</code> 表示 10%。<br>默认值 <code>0</code> 表示直接跟随买一价/卖一价；大于 <code>0</code> 表示设置一个距离。</td></tr><tr><td>&gt; maxChaseType</td><td>String</td><td>条件必填</td><td>最大追逐距离单位。<code>distance</code> 或 <code>ratio</code>。须与 <code>maxChaseVal</code> 成对出现。</td></tr><tr><td>&gt; maxChaseVal</td><td>String</td><td>条件必填</td><td>最大追逐距离值。须为正数。须与 <code>maxChaseType</code> 成对出现。当偏离达到该值时，追逐委托自动撤单。</td></tr></tbody></table>
